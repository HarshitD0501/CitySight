# CitySight frontend

This static Ward Pulse view opens a CesiumJS 1.146.0 3D globe with the original 198 dataset ward boundaries and OpenStreetMap imagery. Choose 2D streets for the locally bundled Leaflet 1.9.4 view. Demand values remain local: the loader reads the D3 export from `public/data/` and validates run/fit IDs. Both renderers share filters, selection and the table. No API key or remote inference is required for the implemented ellipsoid/OSM scene.

3D startup downloads the official, pinned Cesium release `1.146` script (6,080,574 bytes) and CSS, with verified SHA-384 integrity checks, then loads its workers/assets from that same release. There is no npm Cesium installation. Internet and WebGL are required for uncached 3D startup. The loader waits up to 20 seconds and automatically selects Leaflet on download/initialization/render failure or lost graphics context. No default ion services are called. A deployed CSP must allow the pinned Cesium script/style/assets, its blob workers as needed, and OSM images; denied resources trigger recovery. The current static demo does not configure CSP headers.

Use Tilt view, Top down and Globe to move the 3D camera; use plus/minus, drag/scroll and fullscreen controls. The scene uses an ellipsoid, with polygons at height zero. It does not contain measured terrain or photorealistic buildings. Those provider integrations, credentials, licence terms and ward-area coverage remain unconfigured/unverified. The God's Eye View repository was used as a Cesium architecture reference; its application and unrelated live feeds were not copied.

In the Leaflet view, use zoom buttons or keyboard plus/minus, drag or arrow keys to pan, All wards to reset, and Bird’s-eye view for fullscreen 2D. Streets off removes external tiles; failed tiles automatically retain the local polygon view and table. Hover a ward for its name/value, or select it using the map/table. The existing 2D fallback still works without WebGL. Fills remain translucent over streets so labels remain visible.

## Commands

From this directory, install the locked dependencies in a network-enabled environment:

```sh
npm ci
npm run lint
npm run typecheck
npm run verify:assets
npm run build
```

Serve the generated `out/` directory over loopback HTTP. Do not open `index.html` with `file://`; local JSON fetches require HTTP. The artifact bundle is generated by the repository-root `python -m citysight.export_demo --data-dir <public-data-dir> --out-dir frontend/public/data` command before `npm run build`.

Dependency versions are exact in `package.json` and `package-lock.json`. The 2026-11-04 user request supersedes the former MapLibre/no-online-background decision; see ADR-03/08 in `docs/planning/00_IMPLEMENTATION_BLUEPRINT.md`. ISSUE-18 describes the historical MapLibre worker fix; Leaflet now removes that worker requirement entirely. ISSUE-14's zone fix remains in place; current challenge results are a post-fix re-evaluation of an already inspected split.

Dependency installation used integrity-checked, previously cached npm packages through a temporary loopback registry because external npm access and writes to the global cache were denied. The lockfile retains canonical npm registry URLs and integrity hashes; the temporary cache is ignored. ESLint 9.39.5 satisfies the bundled Next lint-plugin peer ranges, unlike the previous ESLint 10 pin. Its npm package is marked deprecated/unsupported: track migration to a mutually supported ESLint/plugin set before wider release. No legacy-peer-deps flag is needed for the resulting dependency tree.

OSM background requests send tile coordinates, normal browser metadata and Referer to OpenStreetMap; complaint records and prediction values are never sent. Attribution stays visible. Use browser caching; do not prefetch/download an offline tile region. The public service is best-effort; select a provider with suitable capacity/terms before broader public deployment. A clean dependency reinstall and full accessibility certification are not implied by a successful build.

## Upstream implementation references

- [Next.js static exports](https://nextjs.org/docs/app/guides/static-exports): `output: "export"` emits static files; request-dependent server features are outside this app.
- [Next.js installation](https://nextjs.org/docs/app/getting-started/installation): documents Node.js 20.9 minimum; the available runtime is Node 22.22.3.
- [Next.js ESLint configuration](https://nextjs.org/docs/app/api-reference/config/eslint): Next 16 uses the ESLint CLI and flat config; lint is run separately from `next build`.
- [Leaflet 1.9.4 stable API](https://leafletjs.com/reference-1.9.4.html): client-only GeoJSON, paths, tile events, bounds, keyboard controls and resize handling.
- [OSM tile usage policy](https://operations.osmfoundation.org/policies/tiles/): visible attribution, HTTPS tile endpoint, caching, Referer and no bulk prefetch.
- [Cesium quickstart](https://cesium.com/learn/cesiumjs-learn/cesiumjs-quickstart/): pinned CDN engine, CSS and static asset base URL.
- [Cesium GeoJSON](https://cesium.com/learn/cesiumjs/ref-doc/GeoJsonDataSource.html), [camera](https://cesium.com/learn/cesiumjs/ref-doc/Camera.html): original polygon entities and camera controls.
